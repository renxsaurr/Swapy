# SWAPY Web App

> **Implementation status: Next.js starter scaffold.** The current home page is the default Next.js starter screen; it is not a SWAPY marketplace experience. Product pages, user journeys, and the MVP have not been approved. See the [product blueprint](../../SWAPY-PRODUCT-BLUEPRINT.md) before interpreting the concept documents as build scope.

## Current setup

This app uses Next.js, React, and TypeScript. From this directory:

```bash
npm ci
npm run dev
```

Then open `http://localhost:3000`. The current entry page is `app/page.tsx`.

## Available scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Run the web app locally |
| `npm run build` | Create a production build |
| `npm run start` | Serve the production build |
| `npm run lint` | Run ESLint |

## Product development gate

Do not interpret the proposed modules, flows, or visual language in the product notes as approved page requirements. Build the user journey only after the client approves the MVP, target market, and relevant operating rules. The [Strategy Validation Plan](../../SWAPY-STRATEGY-VALIDATION-PLAN.md) records the decisions and evidence needed.
