# Promote a Listing or Event

## Purpose
Offer sellers paid visibility that is transparent, relevant, and bounded.

## Eligible Promotion Types
- **Items:** boost a specific listing in relevant search or feed placements.
- **Homes:** feature an eligible home-swap listing only after required completeness and identity checks; never reveal exact private location.
- **Services:** promote to relevant local or remote-search audiences; paid placement is not proof of provider skill.
- **Garage Sales:** promote the event page locally; optionally boost selected event inventory.

## Purchase Flow
1. User selects **Promote** on an eligible listing or event.
2. Show placement, intended audience, duration, price, and Sponsored label.
3. User confirms payment.
4. Listing receives the paid placement while still obeying user filters and moderation.
5. Show campaign views, saves, offers/requests, and event follows.
6. End the campaign automatically; no hidden renewal.

## Ranking Rules
- Sponsored content is visibly labeled.
- Promotion does not bypass eligibility, trust review, or user-selected filters.
- Organic relevance remains meaningful.
- Do not promise a sale, trade, booking, or reach level unless contractually guaranteed.

## Justification
One promotion system can serve each module, but the promoted unit should match user intent: an item, home listing, service, or event. Transparent labels and bounded duration preserve trust and make results measurable.
