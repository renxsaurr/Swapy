# SWAPY

SWAPY is a peer-to-peer marketplace for exchanging, selling, renting, and offering things and services. Its promise is: **Turn what you have into what you want.**

This folder currently contains product and engineering notes, not the web application source code. Start with the [Development Guide](Business%20and%20Platform/00%20-%20Development%20Guide.md) for the product flow, technical design, and build order.

## Main product areas

- [Items](Items/01%20-%20ITEMS.md): sell or swap physical items.
- [Homes](Homes/01%20-%20HOMES.md): short stays, rentals, property sales, and ownership trades.
- [Services](Services/01%20-%20SERVICES.md): agree on work, schedule, and payment or trade.
- [Garage Sales](Garage%20Sales/01%20-%20GARAGE%20SALES.md): create and visit temporary local sales.
- [My Store](My%20Store/01%20-%20MY%20STORE.md): manage and share a member’s listings and events.

## Shared transaction path

Discover → review → request or offer → agree on terms → confirm → pay if needed → hand over or deliver → inspect → complete or ask for support.
