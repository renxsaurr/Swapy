# Create Home Swap Listing

## Purpose
Let an authorized user create a home listing for one enabled transaction type in their location.

## UI Flow
Use focused steps: Transaction type and location → Home details and eligibility → Terms and documents → Privacy and preview.

### Transaction type and location
Select exactly one listing type: short stay/home swap, long-term rental, property sale, or ownership trade. Select the country, state/province/region, and city. Check that this location profile is Approved and Enabled for the selected type before allowing publication or binding inquiries.

### Home details
Collect:
- Listing title and photos
- Approximate area, not exact public address
- Home type, capacity, sleeping arrangements
- Amenities and accessibility information
- House rules, pets, and known limitations or hazards
- Owner/host identity and authority-to-list evidence required by the location profile
- For long-term rentals, sale, or ownership trade, the type-specific documents and disclosures required by that approved profile

Add transaction-specific fields rather than reusing one generic home form:
- **Short stay:** available dates, stay length, capacity, included arrangements, house rules, and any reciprocal swap home.
- **Long-term rental:** rental term, availability/move-in date, rent and included costs, occupancy terms, and application requirements allowed by the profile.
- **Property sale:** asking price and currency, property facts and identifiers required by the profile, included fixtures/items, known material limitations, and sale status.
- **Ownership trade:** trade description plus a separate property record and proposed terms for each side; link each property to its own location profile and due-diligence track.

### Availability and preferences
Collect:
- Available dates or date ranges
- Minimum and maximum stay, if applicable
- Guest count
- Whether the host is seeking a reciprocal home swap or is open to another approved arrangement
- Optional destination or home preferences

### Privacy and preview
Explain what is public and what is restricted. Never make exact address, identity documents, title/deed materials, access details, or sensitive disclosures public. Let the user preview and publish or save a draft. Restrict transactional actions if profile status changes to Suspended.

## Listing Review and Verification Labels
- Run required identity, authority, document, listing, safety, and moderation checks from the enabled location profile.
- Label each check precisely: for example, **Identity checked**, **Authority documents reviewed**, or **Listing reviewed**. State what was checked, when, and what remains unverified. Never imply that SWAPY guarantees title, condition, legality, or safety.
- Keep exact address private until the relevant signed-stage process permits sharing. Keep documents private to authorized participants and reviewers.
- Preserve the published listing version and its evidence/review outcome. Material edits require a new review when the profile requires it.
- If location/type has no Approved and Enabled profile, allow a draft but block publication or binding transaction actions and explain why.

## Justification
Home transaction types need different eligibility and documents. A typed, location-gated form prevents SWAPY from applying the short-stay flow to rentals or ownership transfers while protecting addresses and records.
