# Set Up and Manage My Store

## Purpose
Let a member create and maintain a clear public identity and manage their SWAPY inventory.

## Setup
Ask the member to add a display name, profile image, short bio, approximate service area, and notification preferences. Verification indicators appear only after the relevant checks are completed.

## Dashboard
Provide sections for:
- Active listings
- Drafts and paused listings
- Incoming offers and messages
- Upcoming Garage Sales
- Completed and archived listings
- Basic views, saves, and offers

Actions: create, edit, pause, archive an available item, share store, and manage visibility. Show Reserved and Sold/Traded as transaction-derived states; do not provide a manual sold/traded action. The storefront and Garage Sale inventory link to the same canonical item, rather than creating duplicate items.

## Store State
- Public
- Unlisted/share-link only
- Paused

Pausing a store hides active listings from discovery but preserves transaction access for active deals.

## Justification
A single dashboard reduces the effort to manage multiple listing types. Visibility controls let users share selectively and take a break without losing transaction history.
