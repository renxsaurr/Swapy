# Users Inspect and Complete the Transaction

## Purpose
Give each recipient a clear chance to check their item before the transaction closes.

## Inspection Period
For shipped items, start the inspection period after delivery. For local meetups, users can inspect items together before confirming handover.

A suggested shipped-item default is 48 hours after confirmed delivery. Show the exact deadline in the transaction screen.

## Recipient Actions
- **Accept item**
- **Report a problem**
- **Need more time**

A recipient who needs more time chooses a reason, such as a delayed delivery or inability to inspect. Show the revised deadline if the request is approved.

## Reminders and Completion
1. Notify the recipient when the inspection period starts.
2. Send a reminder before the deadline.
3. If no problem is reported by the stated deadline, mark the item **No issue reported** and complete the transaction under the displayed policy.
4. Notify both users that the transaction is complete.
5. Invite each user to leave a review.

A review should only become available after the transaction reaches a completion state.

## Completed Transaction Screen
Show:
- Items exchanged
- Any cash amount paid
- Handover method
- Completion date
- Review actions
- Report a problem or get help link

## Justification
An explicit inspection period tells users when to check their item and how to raise a concern. Reminders reduce missed deadlines. Making reviews available only after completion ties feedback to an actual transaction.
