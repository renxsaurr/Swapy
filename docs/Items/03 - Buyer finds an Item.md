# Buyer finds an Item

## Purpose
Help buyers discover an item and choose the right next step based on how its owner is willing to exchange it.

## Discovery
Buyers can browse without signing in. They can:
- Search by item or category
- Browse by location
- Filter by condition, distance, and accepted deal format
- Sort by relevance, distance, or newest
- Browse nearby items, recent listings, saved searches, or followed My Stores

## Item Card
Keep the card simple. Show:
- Photo
- Item title
- Asking price, if set
- One compact deal label, such as “For sale,” “Open to swaps,” or “Sale + swaps”
- Optional distance when browsing locally
- Small “Sponsored” label if promoted

## Item Detail Page
Show:
- Full photo gallery
- Description and category
- Condition and known defects
- Included accessories
- Approximate location
- Shipping and meetup options
- Accepted deal formats
- Seller profile and reviews, when available
- Optional seller-stated estimated value, labeled as an estimate

## Detail Page Actions

Do not show every possible offer action as a separate main button. Show one main action based on the listing, with Message and Save as secondary actions.

### Sale at a set price
Show:
- **Buy now — [price]** as the main button
- **Make a cash offer** as a secondary action, if the seller allows offers
- **Message seller**
- Save icon

“Buy now” starts the purchase and agreement flow. The item is not reserved just because the buyer opens the page.

### Sale — open to offers
Show:
- **Make a cash offer** as the main button
- **Message seller**
- Save icon

### Swap-only
Show:
- **Offer an item** as the main button
- **Message seller**
- Save icon

Tapping “Offer an item” opens a form where the buyer selects an item from My Store or adds a one-off item.

### Item + cash
The listing must clarify who may add cash:

- **Seller may add cash for a better item:** show **Offer an item**. The seller can counter with their listed item plus cash.
- **Buyer may add cash with their item:** show **Offer an item + cash**.
- **Cash direction is flexible:** show **Make an offer**, then let the buyer choose cash, an item, or an item + cash.

### Listing accepts multiple formats
Show:
- **Buy now — [price]**, if there is a set sale price
- **Make an offer** for the other accepted formats
- **Message seller**
- Save icon

Tapping “Make an offer” opens a small panel showing only the formats the seller accepts.

## Reservation Rule
Viewing, saving, messaging, or sending an offer does not reserve the item. A fixed-price “Buy now” starts the purchase flow; show clearly when the item becomes reserved during the agreement and payment steps. 

## Promotion Rule
A seller can pay to boost an eligible listing. A boost may increase visibility, but does not guarantee a sale or bypass buyer filters. Label promoted listings “Sponsored.”

## Justification
One main action keeps the detail page easy to understand. The correct action depends on the deal formats the seller selected, so buyers are not shown options the seller will reject.

The item + cash format needs extra clarity because either user could be the one adding cash. Stating the direction on the listing and reflecting it in the button avoids confusing or reversed offers. Message and Save remain secondary because they are useful on every listing but are not the primary transaction action.
