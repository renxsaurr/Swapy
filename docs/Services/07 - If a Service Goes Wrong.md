# If a Service Goes Wrong

## Purpose
Handle no-shows, cancellations, incomplete work, scope disagreements, and payment issues.

## Report Reasons
- Provider did not attend
- Customer was unavailable
- Work not completed
- Result materially differs from agreed scope
- Schedule or cancellation dispute
- Payment issue
- Other

## Support Flow
1. User reports from the service transaction.
2. Show case status and response deadline.
3. Ask both parties for messages, agreed brief, timestamps, and relevant evidence.
4. Review against the confirmed scope and cancellation terms.
5. Offer the applicable remedy: reschedule, agreed correction, partial/full refund where supported, or close with explanation.
6. Allow one appeal with new evidence.

Do not promise a refund or reversal beyond what the payment provider and disclosed policy permit.

## Justification
The signed service brief provides a fair reference for deciding what was promised. A structured reason and response process helps support resolve disputes without relying only on one party’s account.
