# Hourly Price Decay and Event Promotion

## Purpose
Give hosts optional tools to increase event visibility and create transparent time-based urgency.

## Hourly Price Schedule
1. Host selects an item, starting price, floor price, event hours, and drop times.
2. Preview shows every planned change before publishing.
3. Buyer sees current price, next drop, and event end.
4. Schedule changes at the published times.
5. A reservation holds the displayed price only for its stated duration.
6. Host may pause future drops; completed transactions keep their agreed price.

Never reset countdowns or hide the floor price.

## Promotion
Host can promote the event page to relevant nearby audiences or boost selected items. Label sponsored placement. Promotion cannot override distance/category filters or safety moderation.

## Marketing Decision
Promote the event as a neighborhood destination, then use price schedules for opted-in FOMO. Measure attendance and completed handovers, not just impressions.

## Justification
A visible schedule creates urgency without misleading buyers. Event-level promotion helps a host reach local attendees; item boosts can support selected inventory without turning the whole event into advertising.
