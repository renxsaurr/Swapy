# Close a Garage Sale and Handle Issues

## Purpose
Close event inventory accurately and provide a path for cancellation, disputes, or safety reports.

## Event Close Flow
1. Host ends the event or it reaches its scheduled end.
2. Unsold items become active again only after host confirmation.
3. Sold/traded items stay closed and appear in completed transaction history.
4. Host can share a follow-up store link and invite attendees to follow My Store.

## Issue Types
- Event cancelled or materially changed
- Item was already sold
- Item condition differs from description
- Handover or payment issue
- Safety concern

Support reviews the event listing, item details, transaction record, and both parties’ evidence. Immediate safety issues use the priority support path.

## Justification
Closing inventory explicitly prevents stale items from appearing available. Follow-up links turn one event visit into future discovery without automatically sending marketing messages to attendees.
