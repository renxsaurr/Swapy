# Garage Sales

## Purpose
Let hosts create a temporary neighborhood event and let buyers find inventory and complete quick local handovers.

## Flow
Host creates event → adds event inventory → shares page → buyers browse and follow → buyers attend and inspect → sale or trade is confirmed → event closes and unsold items return to the host’s inventory.

## Marketing Decision
Treat Garage Sales as shareable local events. Event pages, following, opt-in reminders, and transparent price schedules create attendance without fake scarcity.

## Justification
A Garage Sale has a fixed time and place, so event discovery and on-site speed matter more than a typical shipped listing. Keeping its event and inventory together helps prevent buyers from responding to already sold items.
