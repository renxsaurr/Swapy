# Buyer Finds a Garage Sale

## Purpose
Help nearby buyers find an event, decide whether it is worth visiting, and plan attendance.

## Discovery
Browse by date, neighborhood, distance, categories, and trade/cash preference. Event cards show event title, date and hours, approximate area, host/store, and a small Sponsored label when promoted.

## Event Page
Show event description, hours, approximate location or host-approved address, accessibility/parking notes, inventory preview, and accepted payment/trade formats.

Actions:
- Follow event
- Save event
- Share event
- View item
- Optional **I plan to attend** confirmation

Following or planning to attend does not reserve event inventory. Individual items may have a short reservation only if the host enables it.

## Marketing Decision
Use shareable event pages, local discovery, and opt-in reminders. Do not show exact residential addresses by default if the host has not chosen to publish them.

## Justification
Buyers need event time, area, and a sense of inventory before traveling. Keeping item detail separate from the event card prevents the event page from becoming crowded.
