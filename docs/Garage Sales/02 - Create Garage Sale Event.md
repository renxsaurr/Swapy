# Create Garage Sale Event

## Purpose
Let a host publish a time-limited event with inventory and clear attendance information.

## Event Setup
Collect:
- Event name, date, opening hours, and event end
- Neighborhood and map area
- Host profile and contact preference
- Event description, accessibility, parking, and relevant safety notes
- Items included in the event
- Whether items are cash-only, trade-friendly, or either
- Optional item-level prices and transparent price-drop schedules

Host may choose whether the exact address is public or shared with confirmed attendees. Do not show a private address without the host’s choice.

## Inventory
Each event item links to the owner’s canonical item record. Do not create a duplicate item or place it in another active listing at the same time. Run the same required-field, prohibited-item, image-safety, and moderation checks as item listings and one-off offer items. A completed event sale or trade changes availability only through the recorded transaction; no manual sold/traded toggle.

## UI Flow
Event details → add items → privacy and attendance settings → preview → publish.

## Justification
Separating event details from the item inventory helps hosts manage the event while keeping each offer clear. Address controls balance event discovery with household privacy.
